# Insta — ভিডিও ডাউনলোডার (Windows)

তৈরি করেছেন **MH & MIK**

yt-dlp ও ffmpeg অ্যাপের ভেতরেই বান্ডেল করা। ফিচার: ভিডিও/অডিও (MP3) ডাউনলোড, প্লেলিস্ট (সর্বোচ্চ ৫০টি, জিপে), সাবটাইটেল (.srt), ডাউনলোড ইতিহাস, "ফোল্ডারে দেখান" বাটন, yt-dlp আপডেট বাটন।
ডাউনলোড করা ফাইল কম্পিউটারের **Downloads\Insta** ফোল্ডারে জমা হয়।

## GitHub থেকে .exe বানানোর ধাপ (Python বা Visual Studio লাগবে না)

1. এই ফোল্ডারের **সব ফাইল ও ফোল্ডার** (লুকানো `.github` সহ) রিপোর রুটে আপলোড করুন।
   টার্মিনাল থাকলে:
   ```
   git init
   git add .
   git commit -m "Insta Windows"
   git branch -M main
   git remote add origin https://github.com/Economics-2/insta.git
   git push -u origin main
   ```
   রিপোতে আগে থেকে ফাইল থাকলে প্রথমে `git pull origin main --allow-unrelated-histories` চালিয়ে তারপর push করুন।
   ওয়েবে আপলোড করলে `.github/workflows/build-exe.yml` ফাইলটি অবশ্যই যেন যায়।
2. রিপোর **Actions** ট্যাবে "Build EXE" চলবে (৫–১০ মিনিট)। না চললে Actions থেকে "Run workflow" চাপুন।
3. সবুজ টিক এলে রিপোর **Releases → Insta (Windows) — Latest** থেকে `Insta.exe` ডাউনলোড করুন।
   (প্রাইভেট রিপো হলে GitHub-এ লগইন করা অবস্থায় ডাউনলোড করুন।)
4. `Insta.exe`-তে ডাবল-ক্লিক করলেই চালু হবে। ইনস্টলের দরকার নেই।

বিল্ডের শেষ ধাপে exe নিজেই নিজেকে পরীক্ষা করে (সার্ভার, yt-dlp, ffmpeg, WebView2 লাইব্রেরি)। কিছু ভেঙে থাকলে বিল্ড লাল হবে, আর লগে কোন ধাপ ব্যর্থ হয়েছে দেখা যাবে।

## নতুন (সংস্করণ ১.৬)

**১. থাম্বনেইল / সেরা মুহূর্তের ছবি:** লাইব্রেরির ভিডিওতে "🖼 থাম্বনেইল" চাপুন, ৬/১২/২৪টি ছবি বেছে নিন। ভিডিওকে সমান ভাগ করে প্রতি অংশ থেকে সবচেয়ে ভালো ফ্রেম (কালো বা ঝাপসা এড়িয়ে) ছবি হিসেবে `নাম (ছবি)` ফোল্ডারে সেভ হয় এবং অ্যাপের ভেতরেই দেখা যায়। ইউটিউব থাম্বনেইল বা কভার বানানোর জন্য সুবিধাজনক। "ফাইলসহ মুছুন" করলে ছবির ফোল্ডারও মোছে।

**২. ফোনে পাঠানো (QR কোড):** লাইব্রেরির যেকোনো ফাইলে "📱 ফোনে পাঠান" চাপলে QR কোড ও লিংক আসে। কম্পিউটার ও ফোন একই Wi-Fi-তে থাকলে ফোনের ক্যামেরায় স্ক্যান করুন: ফোনের ব্রাউজারে ভিডিও/অডিও সরাসরি চালানো যায় আর "ডাউনলোড করুন" চাপলে ফাইল ফোনে নামে। তার বা অ্যাপ লাগে না।
- লিংকটি ৩০ মিনিট পর নিজে বন্ধ হয়। শেষ হলে "শেয়ার বন্ধ করুন" চাপলে সাথে সাথে বন্ধ। শেয়ার না থাকলে ভেতরের সার্ভারটিও বন্ধ থাকে।
- শুধু ওই একটি ফাইলই পাওয়া যায় (লম্বা গোপন লিংক ধরে), ফোল্ডার ঘেঁটে দেখার উপায় নেই, আর শুধু ঘরোয়া নেটওয়ার্ক (192.168.x.x, 10.x.x.x ইত্যাদি) থেকে সংযোগ নেয়, ইন্টারনেট থেকে নয়। তবে **একই Wi-Fi-র যে কেউ লিংকটি পেলে** নামাতে পারবে, তাই পাবলিক Wi-Fi-তে ব্যবহার করবেন না।
- প্রথমবার Windows ফায়ারওয়াল অনুমতি চাইবে: **"Private networks"-এ Allow** দিন।

## সংস্করণ ১.৫

**১. চ্যানেল/প্লেলিস্ট ফলো (নতুন "ফলো" ট্যাব):** ইউটিউব চ্যানেল বা প্লেলিস্টের লিংক দিয়ে "ফলো করুন" চাপুন। Insta নির্দিষ্ট সময় পরপর (১, ৩, ৬, ১২ বা ২৪ ঘণ্টা) নিজে থেকে নতুন ভিডিও খুঁজে আপনার ঠিক করা কোয়ালিটিতে কিউতে দিয়ে নামিয়ে দেয়। ফলো করার মুহূর্তে চ্যানেলে যা আছে তা "দেখা" ধরা হয়, তাই পুরোনো ভিডিও নামে না। চাইলে শুরুতে সর্বশেষ ৩/৫/১০টিও নামানো যায়। একটি ভিডিও কখনো দুবার নামে না। প্রতিবারে সর্বোচ্চ ১০টি নতুন ভিডিও নামে। "এখনই দেখুন" বাটনে সাথে সাথে যাচাই হয়, প্রতিটি ফলো বন্ধ রাখা, কোয়ালিটি/সময় বদলানো বা বাদ দেওয়া যায়। নতুন ভিডিও পেলে Windows নোটিফিকেশন আসে। **এজন্য Insta চালু থাকতে হবে** (ট্রে-তে থাকলেও চলে, সেটিংসে "Windows চালু হলে নিজে থেকে চালু হবে" টিক দিলে সুবিধা)। অ্যাপ চালু হওয়ার প্রায় ২০ সেকেন্ড পরে প্রথম যাচাই হয়। অ্যাপ বন্ধ থাকলে যাচাই হয় না, আবার চালু করলে মিস হওয়া ভিডিও নামে।

**২. সাবটাইটেল ভিডিওতে বসানো:** লাইব্রেরিতে যে ভিডিওর ট্রান্সক্রিপ্ট করা আছে, তাতে "🎞 সাবটাইটেল বসান" বাটন আসে। লেখার সাইজ (ছোট/মাঝারি/বড়), জায়গা (নিচে/মাঝে/উপরে), রং (সাদা/হলুদ) ও পেছনে কালচে বক্স বেছে নিন। ফলে `নাম (সাবটাইটেল).mp4` নামে নতুন ভিডিও তৈরি হয়, যাতে লেখা স্থায়ীভাবে বসানো থাকে (ফেসবুক/ইনস্টাগ্রামে আপলোডের জন্য উপযোগী)। মূল ভিডিও অক্ষত থাকে। বাংলা হরফের জন্য বান্ডেল করা Noto Sans Bengali ফন্ট, না থাকলে Windows-এর Nirmala UI ব্যবহার হয়। SRT-এর লেখা ভুল থাকলে `.srt` ফাইল Notepad-এ ঠিক করে আবার চালান: ভিডিওর পাশের `নাম.srt` বদলালে নতুন বসানোয় সেটিই ধরা হবে।

**৩. নীরব অংশ বাদ দেওয়া:** লাইব্রেরির যেকোনো ভিডিও বা অডিওতে "✂ নীরবতা বাদ দিন" চাপুন। মাত্রা: হালকা (১ সেকেন্ডের বেশি বিরতি), মাঝারি (০.৬ সেকেন্ডের বেশি, প্রস্তাবিত), কড়া (০.৩৫ সেকেন্ডের বেশি)। নীরব অংশ কেটে ছবি ও শব্দ একসাথে ঠিক রেখে ছোট নতুন ফাইল (`নাম (নীরবতা বাদ).mp4`/`.mp3`) তৈরি হয়, কত সময় বাদ গেল দেখায়। কথার দুই পাশে অল্প বিরতি রেখে দেওয়া হয়, যাতে কথা হঠাৎ কাটা না শোনায়। ব্যাকগ্রাউন্ডে গান বা শব্দ চললে নীরবতা ধরা কঠিন, তাই সেক্ষেত্রে ফল কম হতে পারে।

ট্রান্সক্রিপ্ট, সাবটাইটেল বসানো ও নীরবতা বাদ, এই তিনটি কাজ একসাথে একটিই চলে, বাকিগুলো অপেক্ষায় থাকে। চলার সময় শতাংশ দেখা যায় ও বাতিল করা যায়।

## সংস্করণ ১.৪

**১. লাইব্রেরি ও সার্চ:** আগের "ইতিহাস" ট্যাব এখন **লাইব্রেরি**। উপরের ঘরে লিখলে নাম, লিংক এবং (ট্রান্সক্রিপ্ট থাকলে) ভিডিওর ভেতরের কথাতেও খোঁজে, মিলে যাওয়া অংশ নিচে দেখায়। ফিল্টার: ভিডিও / অডিও / প্লেলিস্ট / ট্রান্সক্রিপ্টসহ / ফাইল নেই। সাজানো: নতুন, পুরোনো, বড় ফাইল, নাম। প্রতিটি আইটেমে **খুলুন** (ডিফল্ট প্লেয়ারে), **ফোল্ডারে দেখান**, **তালিকা থেকে সরান** ও **ফাইলসহ মুছুন** (কম্পিউটার থেকেও মোছে, আগে জিজ্ঞেস করে)। **ফোল্ডার স্ক্যান** চাপলে ডাউনলোড ফোল্ডারে আগে থেকে থাকা ভিডিও/অডিও ফাইলও তালিকায় ঢোকে। তালিকায় এখন ২০০০টি পর্যন্ত আইটেম থাকে।

**২. অফলাইন ট্রান্সক্রিপ্ট ও ইংরেজি অনুবাদ:** লাইব্রেরির যেকোনো ভিডিও বা অডিওতে **📝 ট্রান্সক্রিপ্ট করুন** চাপুন, ভাষা বেছে নিন (বা "নিজে থেকে চিনবে")। কথা লেখা হয়ে ভিডিওর পাশেই `নাম.txt` ও সাবটাইটেল `নাম.srt` তৈরি হয়। SRT ফাইল VLC বা অন্য প্লেয়ারে সাবটাইটেল হিসেবে চলে। "ইংরেজিতে অনুবাদ" টিক দিলে যেকোনো ভাষা থেকে ইংরেজি লেখা পাওয়া যায় (`নাম.en.txt`, `নাম.en.srt`)। পুরো কাজ কম্পিউটারেই হয় (whisper.cpp), কোনো ভিডিও বা লেখা বাইরে যায় না।
- প্রথমবার একটি মডেল ফাইল ইন্টারনেট থেকে একবার নামে, এরপর সব কাজ ইন্টারনেট ছাড়াই চলে। মডেল সেটিংসে বাছা যায়: tiny (~৭৫ MB, দ্রুত, বাংলায় ভুল বেশি), base (~১৪০ MB), **small (~৪৭০ MB, ডিফল্ট, বাংলার জন্য সবচেয়ে ভালো)**।
- একসাথে একটি কাজই চলে, বাকিগুলো অপেক্ষায় থাকে। বড় ভিডিওতে সময় লাগে (CPU-র গতির ওপর নির্ভর করে), চলার সময় শতাংশ দেখা যায় ও বাতিল করা যায়।
- **সীমাবদ্ধতা:** অনুবাদ শুধু **ইংরেজিতে** (Whisper-এর নিজস্ব ক্ষমতা)। বাংলায় অনুবাদ ইন্টারনেট ছাড়া এই পদ্ধতিতে হয় না। গান বা কোলাহলের মধ্যে লেখা ভুল হতে পারে, তাই গুরুত্বপূর্ণ কিছু হলে মিলিয়ে নিন।
- GitHub Actions বিল্ডের সময় whisper.cpp নামিয়ে exe-র ভেতরে ঢোকানো হয় (`bin/whisper`)। কোনো কারণে নামানো ব্যর্থ হলে বিল্ড চলতে থাকে, শুধু ট্রান্সক্রিপ্ট বাটনে "ইঞ্জিন নেই" বার্তা আসে। Actions-এর লগে "whisper" ধাপ দেখুন।

## সংস্করণ ১.৩

**১. ব্যাচ ডাউনলোড:** ডাউনলোড ট্যাবে "একসাথে অনেক লিংক নামান (ব্যাচ)" অংশে প্রতি লাইনে একটি করে লিংক পেস্ট করুন (সর্বোচ্চ ৫০টি)। কোয়ালিটি ও অটো কাজ বেছে "সব কিউতে যোগ করুন" চাপুন, লিংকগুলো কিউতে ঢুকে একে একে নামবে। ভুল লিংক বাদ যায় ও কয়টি বাদ গেল দেখায়। Chrome এক্সটেনশনের আইকনে "খোলা সব ভিডিও ট্যাব পাঠান" বাটনও আছে।

**২. ভিডিওর শুধু একটি অংশ নামানো:** লিংক খুঁজে পেলে কার্ডে "শুরু" ও "শেষ" সময় দেওয়া যায় (৯০, ১:৩০, ১:০২:০৩ বা বাংলা অঙ্কে ১:৩০)। শুধু শুরু দিলে শেষ পর্যন্ত, শুধু শেষ দিলে শুরু থেকে নামে। লম্বা লেকচার বা লাইভ থেকে দরকারি অংশ নিতে কাজে লাগে। অংশ কাটতে ffmpeg দিয়ে আবার এনকোড হয়, তাই সময় লাগে এবং অগ্রগতির শতাংশ না-ও দেখা যেতে পারে। প্লেলিস্টে এটি কাজ করে না।

**৩. এক্সটেনশনে কোয়ালিটি বেছে নেওয়া:** ভিডিও পেজের বাটনের পাশে ▾ চাপলে মেনু আসে: সেরা / ১০৮০p / ৭২০p / ৪৮০p / শুধু অডিও (MP3)। বাটনে সরাসরি চাপলে সেটিংসের ডিফল্ট কোয়ালিটিতে নামে। ডান-ক্লিকের "Insta-তে ডাউনলোড করুন"-এও একই সাবমেনু এবং টুলবার পপআপে কোয়ালিটি বাছার ঘর আছে। **এক্সটেনশন আপডেটের পর** `chrome://extensions`-এ Insta-র রিফ্রেশ (⟳) বাটন চাপুন, আর খোলা ফেসবুক/ইউটিউব ট্যাব রিলোড (F5) করুন।

**৪. ক্লিপবোর্ড থেকে লিংক ধরা:** ইউটিউব, ফেসবুক বা ইনস্টাগ্রামের ভিডিও লিংক কপি করলেই Insta-র জানালায় "ভিডিও লিংক কপি করেছেন। নামাবেন?" ব্যানার আসে: **এখনই নামান** (ডিফল্ট কোয়ালিটিতে কিউতে), **খুঁজে দেখুন** (কোয়ালিটি বেছে নামানোর জন্য) বা **বাদ দিন**। শুধু এই সাইটগুলোর লিংক চেনা হয়, ক্লিপবোর্ডের অন্য কিছু সংরক্ষণ হয় না। সেটিংসে বন্ধ করা যায়। ব্যানার জানালা খোলা থাকলে দেখা যায়, ট্রে-তে লুকানো থাকলে দেখা যায় না।

## সংস্করণ ১.২

**১. ডাউনলোড কিউ:** একসাথে সর্বোচ্চ কয়টি ডাউনলোড চলবে তা সেটিংসে ঠিক করা যায় (ডিফল্ট ২টি), বাকিগুলো লাইনে অপেক্ষা করে। "ডাউনলোড তালিকা"-য় প্রতিটি কাজে **থামান / চালু করুন / বাতিল / আবার চেষ্টা** বাটন আছে। থামানো কাজ চালু করলে আংশিক ফাইল থেকেই চলতে থাকে। অ্যাপ ও এক্সটেনশন, দু'জায়গা থেকে আসা কাজই এই তালিকায় দেখা যায়।

**২. সেটিংস ট্যাব:** ডাউনলোড ফোল্ডার বদলানো, ডিফল্ট কোয়ালিটি (এক্সটেনশন থেকে ডাউনলোডেও এটি চলে), ফাইলের নামের ধরন, একসাথে চলার সংখ্যা, গতি-সীমা (MB/s), লাইট/ডার্ক থিম।

**৩. ট্রে ও ব্যাকগ্রাউন্ড:** জানালা বন্ধ করলে Insta ঘড়ির পাশের ট্রে-তে চলতে থাকে, তাই Chrome এক্সটেনশন সবসময় সাড়া পায়। ট্রে আইকনে ডাবল-ক্লিক করলে খোলে, ডান-ক্লিকে "ডাউনলোড ফোল্ডার" ও "বের হন"। Insta দ্বিতীয়বার চালালে নতুন কপি না খুলে আগেরটির জানালা সামনে আসে। সেটিংসে "Windows চালু হলে নিজে থেকে চালু হবে" টিক দিলে কম্পিউটার চালুর সময় ট্রে-তে চালু হয়। ডাউনলোড শেষ বা ব্যর্থ হলে Windows নোটিফিকেশন আসে (বন্ধও করা যায়)।

**৪. ডাউনলোডের পর অটো কাজ (ffmpeg):**
- **MP3-ও বের করুন:** ভিডিওর পাশে আলাদা MP3 ফাইল।
- **ছোট সাইজে কমপ্রেস:** সর্বোচ্চ ৭২০p, আসল ফাইলের বদলে ছোট ফাইল থাকে।
- **৯:১৬ ভার্টিক্যাল:** ১০৮০×১৯২০, ঝাপসা ব্যাকগ্রাউন্ডসহ (ছবি কাটা পড়ে না), আসল ভিডিওও থাকে। শর্ট ভিডিও বানাতে কাজে লাগে।
- ডাউনলোড কার্ডে প্রতিবার বাছা যায়, আবার সেটিংসে ডিফল্ট ঠিক করা যায়।

## Chrome এক্সটেনশন (ফেসবুক, ইনস্টাগ্রাম, ইউটিউব থেকে এক ক্লিকে)

এক্সটেনশন চালু থাকলে ভিডিও পেজে **"Insta-তে ডাউনলোড"** বাটন আসে। চাপলে লিংক Insta অ্যাপে যায় এবং **সেরা কোয়ালিটিতে সাথে সাথে ডাউনলোড শুরু** হয়। অ্যাপের ভেতরে "এক্সটেনশন থেকে ডাউনলোড" অংশে অগ্রগতি দেখা যায়।

**ইনস্টল (একবারই):**
1. Insta.exe চালু করুন। নিচে "Chrome এক্সটেনশন" অংশটি খুলে **এক্সটেনশন ফোল্ডার খুলুন** চাপুন (ফোল্ডারটি `%APPDATA%\Insta\extension`)।
2. Chrome-এর ঠিকানার ঘরে `chrome://extensions` লিখে Enter চাপুন।
3. ডানে উপরে **Developer mode** চালু করুন।
4. **Load unpacked** চেপে ওই `extension` ফোল্ডারটি বেছে নিন।
5. টুলবারে ধাঁধার আইকন থেকে Insta-কে পিন করে রাখতে পারেন।

**ব্যবহার:**
- ইউটিউব ভিডিও/Shorts, ফেসবুক ভিডিও/Reel, ইনস্টাগ্রাম Reel/পোস্ট খুললে নিচে ডানে বাটন আসে।
- ফেসবুক/ইনস্টাগ্রামের ফিডে ভিডিও পর্দায় থাকলেও বাটন আসে (ভিডিওর নিজস্ব লিংক পাওয়া গেলে)। সাইট ডিজাইন বদলালে এটি কাজ না-ও করতে পারে, তখন ভিডিওটি খুলে নিন।
- যেকোনো লিংকে বা পেজে **ডান-ক্লিক → "Insta-তে ডাউনলোড করুন"**।
- টুলবারের Insta আইকন চাপলে "এই পেজটি পাঠান" বাটন ও অ্যাপ চালু আছে কিনা দেখা যায়।
- **Insta.exe চালু না থাকলে** বাটন "Insta অ্যাপ চালু নেই" জানাবে।
- লগইন-লাগা বা প্রাইভেট ভিডিওর (বিশেষ করে ইনস্টাগ্রাম) জন্য টুলবার আইকনে **"লগইন কুকি সাথে পাঠান"** টিক দিন। কুকি শুধু আপনার কম্পিউটারের Insta অ্যাপে যায়।

**নিরাপত্তা:** অ্যাপ শুধু এই এক্সটেনশনের (নির্দিষ্ট ID-র) অনুরোধ নেয়। অন্য কোনো ওয়েবসাইট বা এক্সটেনশন Insta-কে দিয়ে ডাউনলোড চালাতে পারে না।

## নিজের কম্পিউটারে বানাতে চাইলে (ঐচ্ছিক)
1. Python 3.12 ইনস্টল করুন (Add to PATH টিক দিয়ে)।
2. `bin\` ফোল্ডারে `yt-dlp.exe` (github.com/yt-dlp/yt-dlp/releases) ও `ffmpeg.exe` (github.com/yt-dlp/FFmpeg-Builds/releases) রাখুন। ট্রান্সক্রিপ্ট চাইলে whisper.cpp-র Windows রিলিজ (`whisper-bin-x64.zip`) খুলে `whisper-cli.exe` ও সব `.dll` ফাইল `bin\whisper\` ফোল্ডারে রাখুন (ঐচ্ছিক)।
3. `build.bat`-এ ডাবল-ক্লিক করুন। ফল: `dist\Insta.exe`।

## বিল্ড ব্যর্থ হলে
Actions-এ লাল ক্রসে ক্লিক করে এরর লগ দেখুন এবং শেষ ২০–৩০ লাইন কপি করে পাঠান।

## ব্যবহারের টিপস
- প্রথমবার খুলতে কয়েক সেকেন্ড লাগে (ফাইল এক্সট্র্যাক্ট হয়)।
- লিংক পেস্ট করে **Enter** চাপলেই খোঁজা শুরু হয়।
- কোনো সাইট কাজ না করলে অ্যাপের নিচে "yt-dlp আপডেট করুন" চাপুন। আপডেট `%APPDATA%\Insta\bin`-এ জমা থাকে, তাই পরের বারও থাকবে।
- ডাউনলোড ব্যর্থ হলে কারণ লেখা থাকে `%APPDATA%\Insta\logs\last-error.txt` ফাইলে।
- সেটিংস সেভ থাকে `%APPDATA%\Insta\settings.json` ফাইলে।

## সম্ভাব্য সমস্যা
- **Windows SmartScreen / Defender সতর্কতা দিলে:** "More info → Run anyway" চাপুন। exe-তে ডিজিটাল সিগনেচার নেই বলে এটা স্বাভাবিক, অ্যাপটি আপনার নিজের বানানো।
- **"WebView2 পাওয়া যায়নি" বার্তা এলে:** "হ্যাঁ" চেপে Microsoft-এর পেজ থেকে *Evergreen Bootstrapper* ইনস্টল করে আবার চালু করুন। Windows 11 ও আপডেটেড Windows 10-এ এটি আগে থেকেই থাকে।
- **ফাইলের সাইজ:** ffmpeg ও whisper বান্ডেল থাকায় Insta.exe বড় (প্রায় ১১০–১৬০ MB)। মডেল exe-র ভেতরে নেই, প্রথম ব্যবহারে আলাদা নামে (`%APPDATA%\\Insta\\models`)।

## জানা সীমাবদ্ধতা
- ডিজিটাল সিগনেচার ছাড়া exe, ব্যক্তিগত ব্যবহারের জন্য যথেষ্ট।
- শুধু নিজের বা অনুমতিপ্রাপ্ত কনটেন্ট নামান। কপিরাইট ও প্ল্যাটফর্মের নীতি মানা আপনার দায়িত্ব।
